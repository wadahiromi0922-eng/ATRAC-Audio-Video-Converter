# ATRAC Audio Video Converter

Mac DMG build repository.

## How to build the DMG

1. Upload `ATRAC_v32_36_MAC_DMG_BUILDER_SOURCE.zip` to the repository root.
2. Open **Actions**.
3. Select **Build macOS DMG**.
4. Click **Run workflow**.
5. When the workflow finishes, download the `ATRAC-macOS-DMG` artifact.

The workflow uses GitHub's macOS runner to build the app and package the DMG.
